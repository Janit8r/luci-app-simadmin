# 2026-11-02

## SimAdmin 原生 IMS/VoLTE 短信栈移植（设备：WF2 / msm8906，Android 4.4 → OpenWrt 7.3 内核）

背景：`ims/`（mifi44-ims 抽取的协议库，设备实测可收发短信）作为参考，移植进
`SimAdmin-main` 后端，使短信收发在 OpenWrt 上可用；`luci-app-simadmin` 做适配。
策略：IMS 全接管（注册后 MO/MT 都走 SIP）；承载与 AKA 各两条通道自动降级；
LuCI 保留 iframe + 顶部状态条。

### 后端新增 `SimAdmin-main/backend/src/volte/`（约 7.5k 行）
- `mod.rs` 常量/错误码/`ip_bin()`（支持 `SIMADMIN_IP_BIN` 覆盖，OnceLock 只解析一次）
- `aka.rs` `identity.rs` `sip.rs`(加 `RegisterParams.sec_agree` 门控 sec-agree 头)
  `sms.rs` `pcscf.rs` `ipsec.rs` `uim.rs` — 原样移植
- `qmi_raw.rs` 自写裸 QMUX 客户端（/dev/cdc-wdm* 或 @qmi-proxy；WDS/DMS/UIM=0x0b；
  `read_frame` 用 `libc::poll` 限时，字符设备不支持 SO_RCVTIMEO）
- `bearer.rs` IMS PDN：qmicli 优先 → 裸 QMUX 降级；`apply_addressing` 对
  nodad/noprefixroute 不支持时回退；P-CSCF 路由
- `usim.rs` AKA：qmi-proxy（`execute_usim_authenticate_via_proxy`）→ 裸 QMUX UIM；
  另含 `read_ef_smsc()`（EF_SMSC=0x6F42，必须 READ RECORD 不是 READ BINARY；
  支持 TLV tag 0x80 包裹）+ `AT+CRSM=178,28482,1,4,40,"","7F10"` 兜底
- `runtime.rs` 状态机（Phase/Stage/RegistrationMode/Status）、双 UDP socket
  （port_c/port_s，SO_BINDTODEVICE）、REGISTER 两轮 + AUTS 重同步、IPsec 失败回落
  纯 UDP、MO（SMS-SUBMIT→RP-DATA→MESSAGE，等 RP-ACK）、MT（200 OK 空体 + 单独
  RP-ACK MESSAGE，设备实测协议）、MultipartCache + `ims:<md5>` 去重标记

### 编译/测试方法（重要）
本机没有 aarch64-linux-musl 交叉编译器，`cargo check -p simadmin` 会卡在
`ring`/`rusqlite` 的 C 构建。可行做法：
1. 单模块：临时 crate 只依赖 tokio/tracing/libc/socket2/md5 +
   `simadmin-device-runtime`（纯 Rust，可交叉编译到 aarch64-musl）；
2. 整体：复制 workspace（Cargo.toml/crates/backend/src/scripts/build.rs，不含
   target），对 `qmi_raw.rs`（UnixStream→TcpStream、去掉 AsRawFd）与
   `runtime.rs`（`bind_device` 加 `#[cfg(unix)]`）打临时补丁，再在宿主
   `cargo test`；跑测试时设 `SIMADMIN_IP_BIN=/sbin/ip`。
结果：后端零错误；volte 相关 65 个单测全过；全量 202 passed，仅 2 个
`device_network` DDNS 路由测试在 Windows 下失败（依赖系统 `ip route`，与本次改动无关）。

### 内嵌前端契约（从 `www/assets/*.js` 逆向确认，务必保持）
- `GET /api/volte/control` → `data` 必须是 `{ config: {...}, runtime: {...} }` **两层**，
  不能拍平。UI 读 `data.config.feature_enabled / connection_enabled / sms_enabled`
  与 `data.runtime.{phase,stage,registered,failure_count,local_ip,pcscf,interface,
  last_error,registered_at,registration_mode,session_started_at,sent_count,
  received_count,data_path_mode}`
- POST 端点：`/api/volte/feature` `{enabled}`、`/api/volte/sms` `{enabled}`、
  `/api/volte/connection` `{enabled}`（等价 feature）、`/api/volte/reconnect` `{}`
  （等价 refresh）。旧 python 版没有 `/refresh`、`/settings`，这两个是新增的。
- `runtime.stage` 已知键：identity/identity_aka/radio/data_path/pcscf/modem/bearer/
  register_ipsec/register_udp/registered/stopping（未知键原样显示，安全）
- 内嵌 UI 是预编译产物 `root/opt/simadmin/www/assets/*.js`，不要试图改；后端去适配它。

### 交付前必须做的一步
`luci-app-simadmin/root/opt/simadmin/simadmin` 是旧的 aarch64 二进制。新代码要在
OpenWrt SDK 里 `cargo build --release --target aarch64-unknown-linux-musl`
（或用项目原有构建脚本）重新编译后替换，否则 IMS 改动不会生效。
